# Menu design reference

Menu presents commands, navigation and immediate preferences for a single task. Use a labeled button or an icon button with an accessible name as its trigger. A persistent form value belongs to Select. A group of site navigation links belongs to navigation. Forms and arbitrary interactive content belong to Popover.

## Anatomy and density

| Element           | Design                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Surface           | One floating panel with a 1px material edge, a 10px or 0px outer radius and a 4px inner inset. Rows use the resulting 5px or 0px inner radius. No arrow or scrim.                                                                                                                                                                                                                          |
| Size              | Compact S uses 30px rows, 14px icons and 8px inline padding. Default M uses 40px, 16px and 10px. Roomy L uses 48px, 20px and 12px. These are minimum heights. A coarse primary pointer gets at least 44px, including Back.                                                                                                                                                                 |
| Width             | Starting widths are 216px, 240px and 272px. Use the narrower inline space when necessary. A longer menu can use more width in the application up to 352px if the viewport and its parent menu allow it. Keep the same width through an in-place submenu.                                                                                                                                   |
| Leading area      | Reserve a choice-mark column only in a panel with choices. Reserve a second icon column only if the panel uses icons. Labels align across rows and groups. Text-only menus start at the normal row inset.                                                                                                                                                                                  |
| Copy              | A medium-weight action label wraps and grows the row. An optional secondary line gives a concise reason or identifies a destination. It shares the label's alignment and wraps. Never use it for the primary verb.                                                                                                                                                                         |
| Trailing area     | A compact Kbd cap uses the application's platform notation. A submenu chevron uses the same trailing edge. These are separate row types. When a complete cap cannot share the line without crowding the label, put it on its own trailing line. Hide the whole cap if it cannot fit there. Leave the cap passive and expose a shortcut programmatically only when the application runs it. |
| Group and divider | Groups may name a category or a radio set. Their headers and dividers never take focus. Use a divider for a meaningful change of task, especially before a destructive command.                                                                                                                                                                                                            |
| Long lists        | Give the row list a native scrollbar with the compact scrollbar recipe. Scroll only the list. Keep the panel edge and Back visible. Break unbroken text when necessary and avoid horizontal scrolling.                                                                                                                                                                                     |

All six presets use the same structure. Soft gives the panel a matte body and a soft edge. Frost keeps the shared blur, translucent body and top rim from Popover. Pixel uses an opaque square panel, crisp edge and offset shadow. The row wash is neutral, with no accent fill competing with the page. The outer surface and marks use the active theme. Visibility changes are immediate, as are row hover and press. Press deepens the wash in place. A row never moves, glows or adds a second shadow.

## Rows and states

| Row         | Rest and selection                                                                                                                                                 | Activation                                                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| Command     | Primary label, optional secondary icon and Kbd cap. Destructive commands use danger ink on the label and icon in every available state.                            | Run synchronously, then dismiss. If a command opens a dialog or moves focus to another control, preserve that destination.         |
| Link        | Same row rhythm with a real destination. Use a directional or external icon only when it adds information.                                                         | Ordinary activation follows the link and dismisses. Modifier click, middle click and the browser's link menu keep native behavior. |
| Checkbox    | Blank mark lane when off, check when on. The wash describes the pointer or press, so the check persists through changes in interaction.                            | Toggle and keep the menu open. Multiple options can be changed in one visit.                                                       |
| Radio       | Blank mark lane when unselected, dot when selected. Place related options under a shared accessible group name.                                                    | Select the option and dismiss. Reopening shows the chosen option.                                                                  |
| Submenu     | Trailing chevron and a persistent neutral wash while open. In a cascade the chevron points toward the child, including after a collision flip.                     | Hover can open a desktop cascade. Click, tap or a keyboard action opens the submenu explicitly.                                    |
| Unavailable | Muted whole row, including mark, icon, hint and any short reason. Unavailable takes priority over danger, hover or press. Keyboard focus still has a visible ring. | Arrow keys and typeahead may reach the row. Neither pointer nor keyboard executes it.                                              |

Hover shows a restrained translucent wash. Press uses a deeper wash within the same bounds. Keyboard focus uses an inset 2px ring, which remains on focused unavailable rows. Focus and pointer states may overlap without moving the row. Forced colors use Canvas, CanvasText and GrayText, with system Highlight, HighlightText and a visible focus outline. Check, dot, label and chevron remain distinguishable without color. Reduced motion retains immediate feedback.

No available commands is a decision for the invoking surface. Remove actions that never apply, or explain temporary unavailability at the trigger. A nonempty menu may include an unavailable row that users reasonably expect to find. Progress, errors and confirmation move to the initiating surface, a status region or a dialog as appropriate.

## Placement and interaction

- A button menu prefers block-end with logical start alignment. A compact actions icon near a trailing edge can use logical end. Keep 6px to the trigger and 16px to viewport edges. Flip if the other block side offers more room. Shift inline before wrapping. With very little block space keep the menu accessible within the viewport and let the list scroll.
- A cascade starts 6px beyond the parent panel and aligns its first row to the parent row. Try logical end, then logical start, before using an inline submenu. Shift the child along the block axis to keep it visible. The parent row remains marked. A fine pointer pauses about 170ms before opening a branch. Allow diagonal travel to the child without switching the parent and give a departing pointer about 300ms to reach a child before applying a competing hover.
- An inline submenu replaces the list inside the current panel when a second panel cannot fit or the primary pointer is coarse. Its persistent top Back action uses a mirrored caret; the parent row is the return target. Open this mode by explicit activation only. Retain the opening side, alignment and width while the list grows or shrinks. Scroll the list before changing the opening side. The same decisions apply at each level. Keep application menus shallow.
- Press Enter, Space or Down on the trigger to focus the first row. Up opens at the last row. A pointer opens the surface without a keyboard ring on a row. Down and Up cycle, Home and End reach the limits, and typeahead searches row labels. Separators and headings are skipped. The logical forward arrow opens a branch. The reverse arrow or Escape returns from its child. Escape on the root restores the caller. Tab and Shift+Tab dismiss the chain and continue normal traversal. An outside press keeps the outside destination.
- Keep menus non-modal. In implementation use the native Popover API and the ownership rules in [Overlays and Forms](../../../../../docs/concepts/overlays-and-forms.md). Give the menu an accessible name. A button exposes its expanded state. A branch exposes its relationship to the child. Commands and links use the menu item role, and choices expose checked state. Group labels, row descriptions and action names remain distinct.

## Inspect the reference

- In **Menu**, **Commands and sizes**, **Row states and choices** and **Submenu** pin visual states for comparison. The panels are static except for native scrolling. **Open, choose and dismiss** and **Long content and scrolling** let you invoke the menu, explore active states and try keyboard navigation, choices, disabled rows, placement and dismissal.
- In Folio's **Document Reader & Overlays**, open **Document actions** in the toolbar. The action menu shares the toolbar's density. **Compare revisions** changes the active inspector tab.
- The preview supplies one live submenu level and uses a short pointer grace period to demonstrate crossing into the child. It has local command effects and no global keyboard shortcuts. The full pointer-intent, adaptive placement, native focus lifetime and consumer integration are part of the library implementation.
