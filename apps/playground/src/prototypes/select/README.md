# Listbox and Select design reference

This is an approved interactive design reference. It establishes the appearance and intended experience; prototype props and DOM are disposable. It is not exported by `@docouno/unica`.

Open `?item=listbox` and `?item=select`. Open `?item=select&tab=cases&block=live` for real popover opening, focus, searching and dismissal. Other open panels stay in flow so all six materials can be compared at once. Labeled hover, press and focus samples pin appearance without moving DOM focus.

## Purpose and boundaries

Listbox keeps a finite set of choices visible on the parent surface. Select puts the same rows in a compact, anchored panel. Both support single and multiple selection. They share labels, optional descriptions, decorative icons, one-level groups, unavailable options and the same selection indicator.

Use RadioGroup or SegmentedControl for a few short alternatives that should be visible at once. Use Combobox or Autocomplete when the closed field itself accepts typed text. Commands, navigation, interactive row actions and hierarchical trees belong to other families. Combobox in `select.proto.tsx` remains an adjacent composition stand-in outside this design. Free-form string sets use the separate [TagsInput design reference](../tags-input/README.md).

## Anatomy and geometry

| Part            | Decision                                                                                                                                                                                                                                                                                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Listbox surface | Transparent. No background, border, elevation, material variants or field status. An example's surrounding border belongs to its parent.                                                                                                                                                                                                                      |
| Rows            | S/M/L minimum heights 30/40/48px. Label type is S control font / body-s / body-m. Horizontal padding 8/12/16px, vertical padding 4/8/10px, gaps 6/8/10px. The complete text block is centered in the minimum height. Descriptions increase height naturally; icons and checks stay aligned to the first label line, including touch rows.                     |
| Selection       | A fixed trailing check column, 14/16/20px. Semantic accent ink; no full-row accent fill and no nested checkbox. The column is reserved even when unselected.                                                                                                                                                                                                  |
| Optional icon   | A leading fixed column. If any visible row has an icon, every row keeps that column so text does not shift. Icons align with the first label line.                                                                                                                                                                                                            |
| Copy            | Label in primary ink; description in muted ink, 2px below. Description type is caption-l for S/M and body-s for L. Long labels, descriptions and unbroken strings wrap.                                                                                                                                                                                       |
| Groups          | Sentence-case caption-l medium label. Adjacent groups have a subtle separator and 4px clearance. No nested groups or sticky group headings.                                                                                                                                                                                                                   |
| Trigger         | A single-line button, fixed S/M/L height 30/40/48px. Default uses the field recipe. Ghost is a quiet, borderless inline picker with neutral hover/open feedback, without an input underline. The caret stays downward when open; no rotation or translation.                                                                                                  |
| Trigger width   | Full uses its parent width; auto follows content up to the parent width. Icon, summary, optional read-only lock and disclosure/loading glyph each retain their space.                                                                                                                                                                                         |
| Panel           | The shared Popover material: `--bg-overlay`, `--_overlay-border`, `--_overlay-rim`, `--_overlay-shadow-popover`, `--_overlay-backdrop`, and corner motif. Radius is `--surface-s-radius` (10px in Soft/Frost, 0px in Pixel), 4px shell padding. No arrow or extra card inside.                                                                                |
| Panel width     | At least the trigger width or 264px, whichever is larger, limited by the viewport with 16px edge clearance. Logical start alignment, 8px anchor gap. Prefer below; flip above when it offers more space. Preserve that side while filtering, keeping the 8px anchor gap; reconsider if the viewport no longer has room. No automatic conversion into a modal. |
| Scrolling       | Only the option viewport scrolls, up to 22rem and further constrained by available height. Header/search stay fixed. Rows have 4px inner clearance; active-row scrolling never moves the outer page. Use the common native scrollbar recipe.                                                                                                                  |
| Touch           | Option rows and clear-selection action have minimum 44px targets on coarse pointers. Trigger density stays S/M/L; applications must space compact triggers appropriately.                                                                                                                                                                                     |

A fitting list does not reserve a scrollbar gutter. Classic scrollbar space is added only when the option viewport overflows, keeping row insets symmetric when no scrollbar is needed.

Soft uses an opaque matte panel. Frost uses the approved frosted panel and its rim; the underlying scene remains visible through blur rather than through competing decorations. Pixel uses sharp rectangles, crisp offset shadow and registration corners. Selection and focus never translate a row or trigger. Opening, closing and state feedback are immediate in all themes. Loading reuses the shared Spinner, including its round Soft/Frost motion and stepped Pixel cells. Reduced motion keeps the approved static glyph and written status. Select adds no animation of its own.

## State priorities

1. Disabled blocks input and removes the list/trigger from keyboard entry. It suppresses loading and validation feedback, retains explanatory descriptions, and uses disabled ink rather than stacking opacity. Existing selection remains identifiable.
2. Read only remains readable and focusable. The panel opens and search works, but selecting and clearing are blocked. A lock on the trigger and a quiet “Read only” header explain why.
3. Loading keeps the trigger height and saved labels, replaces the disclosure with a spinner, and shows a written panel status. Selection and clearing are unavailable while data is pending. With no catalog, a compact, start-aligned status replaces the list and search is omitted. During refresh, the previous catalog remains readable and browsable beneath a status row; search still filters it. The shared clear button stays in place but disabled. The host retains the previous catalog and labels while a request is pending; only a successful response can establish that an answer was removed.
4. Selection and navigation are independent. Selected rows keep normal text and a check. Hover/active use a neutral plate; press strengthens that plate without movement. Selected + hover/focus retains the check.
5. Keyboard focus belongs to exactly one place: the active row when the list owns focus; the search control when search owns focus; the root list only when there is no enabled row. An open trigger has no remaining focus outline. A validation outline on a closed trigger follows that field's status.

Status glyphs live in the trigger, including ghost fields, so feedback never depends on the border alone. Supporting messages do not duplicate that glyph.

An open trigger keeps its active treatment when the pointer enters or leaves it. Hover adds no further effect in either default or ghost fields.

Status (`neutral`, `info`, `success`, `warning`, `danger`) colors only the trigger and field feedback. It never recolors the popup, groups, options or selection checks. Error feedback stays adjacent to the field, with a concrete recovery instruction. Required is shown beside the label. Disabled fields retain explanatory description rather than a stale validation message.

## Multiple-selection summary

Keep the closed trigger on one line. Show as many complete names as fit, separated by commas, followed by a quiet `+N` for the remaining values. Reserve count and caret space before fitting names. Keep at least the first name; if that name itself is too long, ellipsize it while preserving `+N`. A wide field can show all names. Selection order determines name order. The full string remains in the button's content/accessibility text and title, and all answers are inspectable in the panel.

The multiple-selection header keeps its count, including “0 selected,” so the panel does not jump when the first value is selected or the last is cleared. The shared ghost Button appears only for a nonempty answer and remains disabled during loading. Its footprint stays reserved when multiple selection is empty, including a wrapped or touch-sized header; no invisible action can receive focus.

Do not put removable tag buttons inside the trigger. Applications that need persistent individual removal can place a sibling TagGroup outside Select. This family has no Apply, Cancel or Done footer: choices apply immediately.

## Expected interaction

| Input                                         | Result                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Tab into Listbox                              | One keyboard stop. Start on the selected enabled row, otherwise the first enabled row.                                                                                                                                                                                                                                                                                                                 |
| Enter / Space / ArrowDown / ArrowUp on Select | Open. Start on the selected enabled row, otherwise the first enabled row. A searchable panel focuses search on keyboard/mouse opening; touch opening focuses the list without summoning the screen keyboard. Tap search to type.                                                                                                                                                                       |
| Arrows, Home, End                             | Browse enabled rows without changing the saved answer; no wrap at either edge. In search, Home/End keep native text-caret meaning.                                                                                                                                                                                                                                                                     |
| Typeahead in a list without search            | Jump by label prefix; repeated letters cycle matches. The typeahead buffer expires after 600ms. Descriptions are not the accessible name or typeahead prefix.                                                                                                                                                                                                                                          |
| Click / Enter / Space                         | Single confirms the row and closes Select. Multiple toggles immediately and stays open, without Ctrl/Shift. Repeating a valid selected single choice does not clear it. An unavailable retained row explicitly offers removal; activating it clears only that answer. Space in search inserts text.                                                                                                    |
| Search                                        | Filter labels, descriptions and group names, case-insensitively. Preserve selections hidden by the query. The query is temporary, never a submitted answer.                                                                                                                                                                                                                                            |
| Clear query                                   | The search field's clear action restores the full catalog and keeps focus in search. Selection is unchanged.                                                                                                                                                                                                                                                                                           |
| Clear selection                               | A compact header action, shown for a nonempty multiple selection or clearable single. Single clears and closes; multiple clears while keeping panel and query, returning focus to search/list. No footer clear bar.                                                                                                                                                                                    |
| Escape                                        | Close only this panel and return focus to its trigger. Reset query; keep committed selection. Never dismiss the parent modal or roll back multiple choices.                                                                                                                                                                                                                                            |
| Tab / Shift+Tab / outside press               | Tab and Shift+Tab traverse header actions and search controls in DOM order. Searchable options use arrows from search, without a redundant list Tab stop. Tab after the last panel control closes and moves to the next control after the trigger. Shift+Tab before the first closes and returns to the trigger. No trap or autoaccept. Outside press acts on its target without forced trigger focus. |
| IME Enter                                     | Finish composition; never select an option or submit the containing form.                                                                                                                                                                                                                                                                                                                              |
| Anchor disappears                             | Close the orphaned panel without choosing a value. Reposition for scrolling, viewport resize and the on-screen keyboard.                                                                                                                                                                                                                                                                               |

If the active option is removed or becomes disabled, move navigation to the next enabled option at that position, otherwise the preceding enabled option. Do not change selection or steal focus from an external control.

Each new entry into Listbox and each Select opening restores navigation to the selected enabled row, otherwise the first enabled row. Cancelled navigation does not carry into the next opening.

Opening alone does not mutate an answer. A single choice returns focus to the trigger; an explicit clear does the same. Touch and pointer interaction preserve the search focus while toggling multiple choices. A trigger has a visible label or a meaningful accessible label; row descriptions supplement the primary label. Announce loading, empty results and changed selection without duplicating every visible string. Reduced-motion and forced-colors modes retain written feedback and non-color selection/focus indicators.

## Availability and recovery

| Case                           | Designed result                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Empty selection                | Muted placeholder, normal disclosure. Never silently choose the first option.                                                                                                                                                                                                                                                                                                                           |
| Empty catalog                  | Quiet non-option copy: “No options available.” The trigger can open to explain the state. The empty list remains keyboard reachable.                                                                                                                                                                                                                                                                    |
| No search results              | Keep the query, search clear action and saved summary. Show “No matches for …” with a brief suggestion. No false selectable row and no destructive reset.                                                                                                                                                                                                                                               |
| Fetch failure                  | Application-owned, start-aligned explanation and a shared neutral secondary Retry button on the same edge, with 12px separation. No fixed minimum height or red popup. Keep the saved answer and query; search stays visible but disabled until recovery. Focus Retry, or the error surface without an action. Failure never marks a saved value as removed.                                            |
| Disabled option                | Skip during navigation; it cannot be selected. A previously selected disabled option keeps its check.                                                                                                                                                                                                                                                                                                   |
| Removed selected option        | Append an “Unavailable selection” group with the saved label or “Unavailable option,” never a raw ID. The row says “No longer available · select to remove” and supports pointer/keyboard removal, even for single selection with no replacement. Removing one value preserves other answers; it cannot be added again. Read-only and disabled states block removal. Filtering does not create orphans. |
| All options disabled           | Show the catalog and selected checks. One fallback focus outline on the list, no invented enabled choice.                                                                                                                                                                                                                                                                                               |
| Long content / RTL / 120% text | Rows expand, the trigger stays one line, `+N` and disclosure remain visible, logical columns mirror. Text uses its own direction; no horizontal scrolling.                                                                                                                                                                                                                                              |

## Inspection and implementation handoff

Listbox States covers density, rich anatomy, selection-state combinations, availability, wrapping/scrolling and surfaces. Its two compositions preview permissions for one chosen role and derive a CSV header from multiple chosen columns. Select States covers field and inline roles, open anatomy, trigger states, field feedback, search, recovery, availability, summaries and live interaction. Its two compositions sort a document list and filter an activity list by source. Existing composition consumers are the collection sort field, invite role/expiry, preferences and the editorial choice-panel stand-in; they consume the same prototypes.

The live harness implements local choices, search, native auto-popover, basic flip/shift, focus return and dismissal. In-flow open studies deliberately stay open after a single choice. Preview data state controls the recovery catalog across themes. Try again restores local data and returns focus to the list that requested it, on its saved region. These are inspectable design decisions, not a reusable library engine.

Library implementation must preserve these outcomes while designing the final React 19 API, localization slots, collection model, complete ARIA associations and announcements, controlled/uncontrolled authority, orphan-label retention, synchronous active-row recovery, native hidden-select form submission/reset/required/disabled-fieldset behavior, nested-layer coordination and cross-browser positioning. The prototype does not claim those guarantees. In particular, form attributes on the preview trigger do not serialize a Select answer.

Reference practices: [WAI-ARIA Listbox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/), [React Aria ListBox](https://react-aria.adobe.com/ListBox), [React Aria Select](https://react-aria.adobe.com/Select). The design explicitly commits on activation rather than arrow navigation and keeps Escape as close-without-clearing.
