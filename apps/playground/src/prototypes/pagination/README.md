# Pagination design reference

Pagination moves through a collection with a known number of pages. Use it under results, an audit log or a directory. A page number always refers to the same position in the current result set. Put the record count, page-size control and data feedback in the collection layout. Show the collection's empty state on zero results. Omit the entire navigation when the page count is zero, one or invalid.

## Anatomy and layout

| Part             | Design                                                                                                                                                                                                                                                                                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Row              | Previous chevron, numbered window or compact position, then Next chevron. Keep a 6px gap. The row has no background, wrapper border or divider. The consumer places it at the logical end of a results footer or centers it under a browse view. Reserve 4px around the row for focus.                                                                            |
| Size             | Use S at 30px with a 14px icon for dense footers, M at 40px with a 16px icon for ordinary collections, and L at 48px with a 20px icon for roomy browse views. Use body XS, S and M at the respective sizes. A coarse primary pointer raises both dimensions of interactive targets to at least 44px. Use the same density for a row and its neighboring controls. |
| Number and gap   | Center tabular numerals and the ellipsis in uniform slots. Each slot is at least square and widens for the longest page label with 4px inline padding and a reserved 1px edge on either side. Directional targets remain square. An ellipsis is a low-emphasis, passive omission marker.                                                                          |
| Compact position | Show the localized equivalent of “Page 4 of 24” between the chevrons, with the current number in stronger neutral ink. Reserve enough space for the longest current label at this total so serial steps don't move the arrows. Keep the chevrons in one line. When the text wraps, keep each number beside its label where space allows.                          |

For up to seven pages, show every page. With eight or more, show seven middle slots and preserve both endpoints. On the first four pages, show the initial run `1 2 3 4 5 … 24`. On the last four, show `1 … 20 21 22 23 24`. Between those runs, show the current page and its immediate neighbors, as in `1 … 11 12 13 … 24`. If a gap would hide one page, show its number. At page 5 of 8 the result is `1 … 4 5 6 7 8`. Reserve geometry for a fixed total so all steps, including 9 to 10 and 999 to 1000, keep both chevrons at the same positions.

Use compact at mobile widths. The default preview shows numbers when the row has at least 360px of available width and the full track fits with the actual text size and pointer targets. A consumer may request numbered pages in a tighter space when the track fits, or use compact at any width. Compact is the fallback when the numbered row would overflow. Resolve the visible projection before paint and expose one set of controls. With RTL, Previous starts at the right, progression runs toward the left and both chevrons mirror. The logical order and names stay intact.

Place the visible result range beside the navigation as a sibling in the collection footer. The range goes at inline-start and the pager at inline-end when both fit. In a narrow footer, put the range above the pager with an 8px gap and align both to inline-start. Give the range text its own reading direction in mixed-direction layouts. The collection owns the separator and its spacing. A one-page collection can still show its range. An empty collection shows its empty message in the results area.

## Material and states

| State           | Treatment                                                                                                                                                                                                                                                                                                        |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Rest            | Use transparent cells, neutral secondary ink and the theme's control radius. Use the same neutral recipe for page targets and chevrons.                                                                                                                                                                          |
| Current         | Fill the cell with the theme's soft accent and use a bold accent numeral, following Calendar's selected day. Soft uses a warm matte tint, Frost a cool tint and Pixel a square plate. The fill and weight show the current page on both base and floating surfaces. The perimeter stays clear.                   |
| Hover and press | Tint the surface under an available number or chevron with 10% primary ink on fine-pointer hover and 17% on press, following Menu. Use primary ink for the numeral or chevron. Feedback is immediate. The current plate stays steady during hover and press. Touch receives press feedback and releases to rest. |
| Focus           | Paint a 2px theme focus ring with a 2px offset. It stays distinct from the filled current plate.                                                                                                                                                                                                                 |
| Boundary        | Reserve the same arrow position and show the glyph in disabled ink. Suppress activation, hover, press and sequential focus.                                                                                                                                                                                      |
| Forced colors   | Use Highlight and HighlightText for the current page and Highlight for the separate focus contour. Use GrayText for unavailable arrows and gaps. Enabled peers and chevrons follow system control ink and gain a system edge on hover or press.                                                                  |

The row uses immediate state changes at every motion preference. There is no sliding highlight, movement on press or animated rearrangement when the window advances.

## Interaction

- Use a named navigation landmark with list semantics. Give the arrows localized names for Previous page and Next page, and the numbered controls accessible names such as Page 12. Mark the numbered current item with `aria-current="page"`. Exclude gaps and the hidden compact sizing text from speech and focus. The compact label conveys the current position as ordinary text.
- Use buttons for an in-place update. Enter, Space and clicks on an available target request the corresponding page. The current button stays focusable and has no side effect. An owner-controlled value keeps its current plate and data until the owner accepts the request. Use links with real destinations when the pages have addresses. Links keep native activation, modifier clicks, copy, history and the current page's real destination. A boundary link placeholder has no destination and is skipped during traversal.
- Tab and Shift+Tab follow the document order. A step that leaves its control available keeps focus there. Keep the focused number when the same visible page stays in the row. When a focused control disappears or a focused arrow reaches its boundary, use the visible current number. In compact, use the remaining step at a boundary. If a resize hides a focused number, use Next when available and Previous at the last page. Preserve focus outside the pager. If an external update removes the entire pager with focus inside it, the consumer moves focus to the result heading or other meaningful result target.
- Replace results in place for local collections. Keep the footer stable during a pending request and let the result region report progress or failure. Move the current plate when the matching page is committed. A failing request leaves the last confirmed page and its data visible. Let the consumer announce the updated range once. A newly applied filter can reset page position to 1 while leaving focus on the filter. For document navigation, the destination owns focus, title and scroll.

## Inspect the reference

- **Control sizes** and **Numbered windows** start with comparable cases. All rows can be stepped, including the five-digit range.
- **Pointer, focus and boundaries** has a pinned comparison and a live two-page row. **Compact in narrow columns** shows the compact equivalent, long labels and keyboard behavior at each edge.
- **Collection footer** and **Inside a floating surface** show the same live list and footer in the page flow and in an open popover. The range and list update together. The list reserves its three-row space on the shorter last page so the footer stays in place. The base examples also show a one-page collection and an empty collection. **Addressable pages** uses real fragment links and browser history.
- In Folio's **Document Collection & Date Filter**, Next changes the table or cards and the result range. Tier-0 and Verified reset the page. Drafts shows the empty result. The table checkbox acts on its current page and prior selections remain available across pages. See the [Folio composition](../../../../../docs/compositions/folio.md).

The preview provides local state, native fragment navigation and immediate boundary and compact-switch focus examples. The library implementation owns router integration, server rendering, localization, full focus restoration across external changes and the public API.
